Rules

  • Single hue encodes magnitude, never category. The ladder is volume; categories separate by position, shape, or label, not a rainbow.
  • Takeaway captions label the meaning, not the axis. "Throughput doubled after W4", never "Quotes per week, weekly".
  • Mono microlabels to 10px. Chart-internal labels are machine artifacts; everything read as a sentence is body.
  • Never color-alone. A second encoding (position, pattern, label) always rides along.
  • Grid from --chart-grid, labels from --chart-label. Charts are token consumers like any surface.
  • An emphasized endpoint beats a legend. Point at the number that carries the takeaway.
