States floor

  • Every component ships all contract states. Hover, focus-visible ring (2px), active press, disabled, loading, empty, error. The happy path alone is unfinished.
  • Touch targets 44px. Compact controls earn their size with surrounding clear space.
  • Never color-alone. Status pairs color with a word, count, or shape.
  • Skeletons mirror the real layout. Loading is a state of the real component, not a spinner page.

Navshell

  • Copy, never approximate. The navshell ports verbatim from components.css; registers substitute values only.
  • Two tiers separate by shade, never a hairline. Light: bright pill leads on recessed frame. Dark: inverted.
  • Active tab: bloom + label. The radial bloom is a named accent device; the label opens inside it.

Do / don't

DoOne matte accent per view, spent on the primary action.
Don'tA second accent, a colored glow, or an accent that is everywhere.
DoPrimary and secondary equal-sized; the fill says which leads.
Don'tA bigger button for the primary action.
DoRhythm from the spacing scale, at class level.
Don'tInline margins per screen. The spacing gate fails them.
DoBody type for everything a human reads.
Don'tUppercase tracked-out mono footnotes.
