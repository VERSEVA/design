Color roles

click a swatch to copy its var

Roles are fixed portfolio-wide; the theme supplies values. One accent per brand, with a usage budget: CTAs, key emphasis, signature moments. Values shown resolve live from the active theme.

Floors: body text 4.5:1 · large text, labels and UI parts 3:1 · --text-3 never sets body copy. Ratios above are computed live; a failing pair does not ship.

Type scale

ratio ~1.25 · 16px base

Loud display, quiet body. Display roles carry the brand voice; body stays calm and never drops below 16px. Mono is for short uppercase labels only, never body or fine print.

Spacing

4px base · the scale is the only source of spatial values

Marketing sections breathe at --s-9/--s-10 vertical rhythm; product surfaces run --s-5/--s-6. Containers: prose 65ch, content 72rem, wide 80rem. When in doubt, add space.

Radius & elevation

hairline-first · shadows reinforce, never carry

Each register declares one radius posture (sharp = authority, soft = approachability) and applies it everywhere. Elevation starts at a hairline; shadows stay physically plausible; on dark, raised surfaces also lighten.

Navigation patterns

the navshell · two tiers by shade · the active tab opens its label

Mobile: the NAVSHELL, ported 1:1 from the App Experience. A frosted container FRAMES an inset main-tab pill with a 6px gap; tiers separate by shade, never a hairline (light: bright main pill leads; dark: inverted, lighter frame, darker recessed pill). Tabs are icon-only; the ACTIVE tab opens its label inside the accent bloom. The sub-nav tier appears only for tabs with real sub-sections (Train, Community, Wellness); Home and You render single-tier. Click the tabs. Desktop: console sidebar with a context switcher, grouped tree, ONE active item; the topbar divides content and nothing sits on top of it.

Always true

the digest · doctrine lives upstream
  1. Hierarchy first. Every surface answers "where do I look first" instantly. When principles conflict, hierarchy wins.
  2. Roles are fixed, values are per-brand. A new role gets proposed in design-core for everyone, or it doesn't exist.
  3. One accent per view, with a budget. An accent that is everywhere has stopped being one.
  4. Contrast floors are contract. 4.5:1 body, 3:1 large text and UI parts. The board computes them live.
  5. Every component ships every state. Default, hover, active, focus-visible, disabled, loading, error. Plus empty/loading/error for every data surface.
  6. Type carries the brand. Loud display, quiet body, 16px body floor, mono for labels only. Max 2 families + mono, pairing justified.
  7. Space is a design element. 4px scale only; marketing rhythm floor 96px; when in doubt, add space.
  8. Hairline-first elevation. Shadows subtle and plausible; signature shadows need a stated budget.
  9. Motion: transform + opacity only, tokened durations and easings, reduced-motion honored, nothing linear.
  10. No dark patterns. No countdown timers, fake scarcity, exit popups, or confirm-shaming, on any brand.

Sync protocol: the package files (tokens.css, components.css, docs/) and each brand's theme.css are the source; this board is the render. Token values arrive by <link>, so token drift is structurally impossible; specimen markup still updates in the same change as any contract edit. Drift is a defect: log it to design-core/learnings.md.
